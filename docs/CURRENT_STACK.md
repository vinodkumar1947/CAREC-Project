# CAREC Current Engineering Stack

CAREC currently develops a simulation-first ROS 2 autonomous wheelchair stack.

## Active scope

- ROS 2 Jazzy interfaces and packages
- digital wheelchair model
- Gazebo / ros_gz simulation
- RViz2 visualization
- manual and shared control
- localization, mapping, and navigation
- perception and sensor fusion
- independent safety supervision
- deterministic fault injection and scenario testing
- machine-readable evaluation evidence

## Out of current scope

ESP-IDF, ESP32, SenseCAP Watcher, device-specific firmware, cloud/mobile applications, and physical wheelchair integration are not part of CAREC Sim 0.1.

Future physical integration requires separate requirements, ADRs, safety review, and evidence.

GitHub `main` is the engineering source of truth. GitHub Issues track execution. GitBook publishes approved documentation from `main`.
