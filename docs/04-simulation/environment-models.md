# Environment Models

Status: Proposed
Owner: Simulation Workstream
Last Updated: 2026-08-23
Related Issues: CARE-011
Related ADRs: ADR-0001

Start with a small indoor world containing corridors, doorway widths, turns, static furniture, ramps or thresholds, and a marked drop-zone surrogate. Assets need license/provenance metadata, dimensions, stable spawn locations, and accessibility context. Later worlds should add dynamic people surrogates and varied lighting without replacing the stable regression baseline.
