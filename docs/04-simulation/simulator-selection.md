# Simulator Selection

Status: Proposed
Owner: Simulation Workstream
Last Updated: 2026-08-29
Related Issues: CARE-001
Related ADRs: ADR-0001

Evaluate the CAREC simulation baseline and credible alternatives against ROS 2 integration, differential-drive and sensor fidelity, headless CI, deterministic control, accessibility-world authoring, compute and resource requirements, licensing compatibility, ecosystem maturity, and maintainability. Produce a scored comparison and proof of concept. The current project baseline is Ubuntu 24.04 LTS, ROS 2 Jazzy, Gazebo Harmonic, Nav2, SLAM Toolbox, RViz2, ros2_control/gz_ros2_control, and ros_gz. NVIDIA Isaac Sim remains an advanced Phase 2 option for high-fidelity simulation rather than the contributor baseline.
