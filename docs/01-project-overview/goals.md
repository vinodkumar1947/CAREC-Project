# Goals

Status: Proposed
Owner: Project Maintainer
Last Updated: 2026-08-23
Related Issues: TBD

- Preserve user agency across manual, assisted, and autonomous modes.
- Provide a reproducible, hardware-independent simulation environment.
- Separate intent, autonomy, safety supervision, and physical actuation.
- Support modular ROS 2, firmware, perception, navigation, mobile, and optional cloud work.
- Make requirements, hazards, tests, decisions, and evidence traceable.
- Enable remote contributors to deliver independently reviewable work.
