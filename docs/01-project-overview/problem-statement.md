# Problem Statement

Status: Draft
Owner: Product Workstream
Last Updated: 2026-08-23
Related Issues: TBD
Related ADRs: TBD

Powered-wheelchair users encounter narrow passages, clutter, drop-offs, dynamic obstacles, fatigue, and changing support needs. Closed, vendor-specific systems can make experimentation and adaptation difficult. CAREC explores an open architecture for warning, shared control, and supervised indoor navigation while treating unintended motion as a primary hazard.

This statement does not claim one solution fits every user or wheelchair. User research, accessibility review, wheelchair-specific interfaces, and clinical or regulatory expertise remain required.
