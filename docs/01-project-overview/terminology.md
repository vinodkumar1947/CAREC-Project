# Terminology

| Term | Meaning |
|---|---|
| User intent | A motion or destination request originating from the wheelchair user. |
| Safe state | A documented state that prevents further hazardous motion; initially a latched zero-motion command in simulation. |
| Safety supervisor | Independent component that validates, limits, or rejects motion commands. |
| Shared control | User commands modified by explicit assistance and safety constraints. |
| HIL | Hardware-in-the-loop testing with real components and simulated surroundings. |
| ODD | Operational design domain: environments and conditions in which a capability is intended to operate. |
| ADR | Architecture Decision Record. |
| Preliminary | Engineering material that is not certification, regulatory approval, or validated clinical guidance. |
