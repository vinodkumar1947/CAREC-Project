# Use Cases

Status: Draft
Owner: Product Workstream
Last Updated: 2026-08-23
Related Issues: TBD
Related ADRs: TBD

1. A user directly drives while CAREC monitors for a defined imminent collision.
2. Assisted mode limits speed in a narrow corridor and helps align with a doorway.
3. A supervised user requests “take me to the kitchen” in a mapped indoor environment.
4. A caregiver issues an authorized stop or receives non-sensitive status.
5. A remote engineer runs the same scenario and verifies deterministic safety behavior without hardware.

Each use case requires acceptance criteria, foreseeable misuse analysis, accessibility review, and a defined fallback to manual control or safe stop.
