# Vision

Status: Proposed
Owner: Project Maintainer
Last Updated: 2026-08-23
Related Issues: TBD
Related ADRs: TBD

CAREC seeks to become an open, modular platform for safer powered-wheelchair mobility. A user should be able to retain direct control, request assistance when useful, and eventually select an indoor destination while a separately enforced safety layer constrains motion.

Progress is evidence-based and incremental: simulation before hardware, unoccupied testing before occupied testing, and supervised validation before any broader claim. See [goals](goals.md), [non-goals](non-goals.md), and [safety philosophy](../06-safety/safety-philosophy.md).
