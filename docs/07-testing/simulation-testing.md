Run versioned scenarios with fixed seeds and record world/model versions, parameters, commands, faults, collisions, minimum clearance, latency, completion, and stop reason. Include nominal, boundary, randomized, and injected-failure cases. A visual demo without machine-readable evidence is not a regression test.
