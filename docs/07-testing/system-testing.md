# System Testing

Status: Proposed
Owner: Testing Workstream
Last Updated: 2026-08-23
Related Issues: TBD
Related ADRs: TBD

System tests evaluate end-to-end use cases and hazards in a declared configuration and ODD. Verify mode transitions, input priority, sensing, planning, safety intervention, actuation feedback, logging, startup/shutdown, update rollback, and recovery. Requirements and hazard coverage must be reported, including failures and exclusions.
