# Hardware Testing

Status: Proposed
Owner: Hardware and Safety Workstreams
Last Updated: 2026-08-23
Related Issues: TBD
Related ADRs: ADR-0003 through ADR-0005

Hardware testing begins with isolated components, fixtures, current-limited power, and unoccupied platforms. Protocols require identified equipment, calibration, expected limits, emergency stop, observers, exclusion zones, abort conditions, and retained results. Repository documentation does not authorize a contributor to connect to wheelchair controls.
