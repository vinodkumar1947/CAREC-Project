# Project Aim and Boundaries

## Aim

Develop and openly evaluate reusable software that can assist powered-wheelchair users through hazard awareness, shared control, and supervised indoor navigation.

## Human outcome

CAREC should increase user agency rather than replace it. The system should communicate why it slowed or stopped, preserve manual override, and support customization with users, families, therapists, clinicians, and accessibility specialists.

## Engineering outcome

Produce a simulator-first reference platform with stable interfaces for perception, localization, planning, shared control, safety supervision, metrics, and model-specific platform adapters.

## Non-goals for the foundation release

- Unsupervised or occupied-wheelchair autonomous operation.
- A medical-device or regulatory approval claim.
- Direct motor access from community code.
- Guaranteed physical compatibility with every wheelchair.
- Outdoor road navigation.
- A paid cloud, proprietary simulator, or GPU requirement.
- Replacing caregivers, clinicians, or manufacturer safety systems.

## Compatibility statement

CAREC targets a platform-agnostic software core. Physical compatibility is granted only to an individually tested combination of wheelchair, controller, adapter, configuration, sensors, mounting, and software release.

## Release principle

Simulation performance is evidence, not proof of physical safety. Physical releases require additional owner-controlled bench and supervised validation.
