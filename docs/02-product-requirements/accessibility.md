# Accessibility Requirements

Status: Draft
Owner: Product Workstream
Last Updated: 2026-08-23
Related Issues: TBD
Related ADRs: TBD

Interfaces should support multiple input and feedback modalities, adjustable timing, clear language, high contrast, scalable text, non-color-only alerts, screen readers, switch access, and reduced cognitive load. Safety alerts must be distinguishable without relying on one sensory channel. Designs require review with wheelchair users and accessibility specialists; assumptions about ability, caregiver access, or preference must be documented.
