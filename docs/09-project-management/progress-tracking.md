Use GitHub Projects first; do not build a custom dashboard without a demonstrated requirement. Suggested views and fields:

- current milestone and roadmap phase;
- workstreams and owners;
- open, Ready, In Progress, Blocked, and completed issues;
- pull requests awaiting review;
- active contributors based on a defined recent window;
- good-first issues;
- hardware-required and hardware-independent work;
- recent approved/proposed ADRs.

Progress is accepted deliverables and evidence, not activity, issue count, lines of code, or invented percentages. A future Notion or other dashboard may mirror links but GitHub remains authoritative.
