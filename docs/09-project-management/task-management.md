GitHub Issues are the source of truth for engineering tasks; GitHub Projects is the initial dashboard. Each issue records type, workstream, priority, difficulty, hardware need, safety class, milestone, dependencies, owner, deliverable, acceptance criteria, and verification. Use the workflow in [issue-workflow](../08-contributors/issue-workflow.md) and the labels in [labels.yml](../../.github/labels.yml).
