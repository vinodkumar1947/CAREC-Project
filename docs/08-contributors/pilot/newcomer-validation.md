# Newcomer onboarding evidence

Create a task issue using this template. Two different newcomers must complete it; do not infer results or collect disability/medical information.

```text
Role: newcomer A / newcomer B (public handle optional)
Commit or PR tested:
Date:
OS and CPU architecture:
Browser and version:
Path: ZIP/direct-file or localhost

[ ] Located Start Here without a private walkthrough
[ ] Loaded illustrated sample
[ ] Confirmed first finding; dismissed second; saw 2 / 3 reviewed
[ ] Exported report with automatic_inference=false and both decisions
[ ] Selected a non-sensitive local test video; sample findings disappeared
[ ] Added an observation within the video's duration and exported it
[ ] Located an appropriate task and understood its acceptance criteria
[ ] Opened a small PR (link), or recorded the precise blocker
[ ] Followed the public review route

Time to first successful demo:
Commands tried and errors (remove private data):
What was unclear:
Private help needed: None / describe what documentation was missing
PR result: opened / checks passed / review received / merged (record separately)
Suggested documentation improvement:
```

A maintainer reviews the evidence and records pass/fail per criterion. Report operating systems and browsers actually tested; do not generalize Linux evidence to Windows or macOS. Store only sanitized logs. Do not attach household or participant footage.
