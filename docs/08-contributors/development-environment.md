# Development Environment

Status: Proposed
Owner: Developer Experience Workstream
Last Updated: 2026-08-23
Related Issues: CARE-004, CARE-043
Related ADRs: ADR-0001, ADR-0002

The repository currently supports Python 3 host tests and a development container. Run `./scripts/bootstrap.sh --check`. The future M0 environment is expected to include Ubuntu, ROS 2, a simulator, RViz, Nav2/SLAM tools, C++, Python, and OpenCV, but versions remain proposed until ADR approval. Document exact versions and one-command setup before making them required.
