# Hardware Workstream

Status: Proposed
Owner: Hardware Workstream
Last Updated: 2026-08-23
Related Issues: CARE-029, CARE-030
Related ADRs: ADR-0003, ADR-0004, ADR-0005

Owns electronics, power, sensors, mounting, mechanical integration, motor interfaces, PCB work, BOMs, and verification fixtures. Physical work is owner-controlled. Contributors can create interface specifications, CAD concepts, FMEAs, test fixtures, and mock drivers without a chair. Existing purchased or investigated parts do not constitute an approved autonomy platform.
