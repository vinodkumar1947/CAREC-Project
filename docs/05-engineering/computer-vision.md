# Computer Vision Workstream

Status: Proposed
Owner: Vision Workstream
Last Updated: 2026-08-23
Related Issues: CARE-020 through CARE-022
Related ADRs: ADR-0003, ADR-0007

Owns people, doorway, obstacle, and scene-understanding research. Every model or algorithm needs a model card or equivalent record, dataset provenance, label definition, evaluation slices, latency results, uncertainty handling, and documented failure cases. Vision output shall not directly command motors.
