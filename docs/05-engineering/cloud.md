# Cloud Workstream

Status: Proposed
Owner: Cloud Workstream
Last Updated: 2026-08-23
Related Issues: CARE-033, CARE-034
Related ADRs: ADR-0008

Cloud services are optional and non-safety-critical. Possible scope is consented telemetry, remote diagnostics, release metadata, and aggregate analytics. CAREC must reach a safe state without connectivity. Minimize data, remove personal identifiers, document retention, authenticate access, and never expose a direct internet-to-motor path.
