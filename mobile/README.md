# CAREC Mobile

Status: Proposed

Owner: Mobile Workstream

Last Updated: 2026-08-23

Related Issues: CARE-031, CARE-032

Related ADRs: ADR-0008

This directory will contain an accessible user/caregiver application. Begin with mock data and flows for status, mode visibility, destination selection, alerts, and authorized stop. Local user priority, authentication, consent, privacy, offline behavior, and non-color-only feedback are required. No production app or remote motion control is currently implemented.
