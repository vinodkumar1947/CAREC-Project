# Submission Checklist — ISICVA 2026

**Portal:** https://cmt3.research.microsoft.com/ISICVA2026  
**Deadline: June 15, 2026**

---

## Springer LNCS Format Requirements

- [ ] Template downloaded from https://www.springer.com/gp/computer-science/lncs/conference-proceedings-guidelines
- [ ] Paper length: **8–15 pages** (including references and figures)
- [ ] Font: Computer Modern (LaTeX) or Times New Roman 10pt (Word)
- [ ] Margins: as per LNCS template — do not alter
- [ ] Title: title-case, no abbreviations in title
- [ ] Authors: full names, affiliations, email — no titles (Dr., Prof.)
- [ ] Abstract: 150–200 words, no citations, no figure references
- [ ] Keywords: 4–6 keywords after abstract
- [ ] Figures: min 300 DPI, numbered, captioned below figure
- [ ] Tables: numbered, captioned above table
- [ ] References: numbered [1], [2]… IEEE/ACM/Springer format
- [ ] References: minimum 15 references, preferably recent (2019–2026)
- [ ] No page numbers in submission (added by publisher)
- [ ] Blind review: **remove author names and affiliations** from submission PDF if double-blind (confirm with organisers)

---

## Content Checklist

### Before Writing
- [ ] Confirm track: **Track 4 — Smart Vision Applications**
- [ ] Review CFP topics align with paper content
- [ ] Check ISICVA 2025 proceedings (Scopus) for scope and format reference

### Paper Content
- [ ] Abstract written and ≤ 200 words
- [ ] Introduction: problem, gap, contribution clearly stated
- [ ] Related work: ≥ 5 relevant cited papers
- [ ] System architecture: block diagram + description
- [ ] Implementation: sufficient detail to reproduce
- [ ] Results: quantitative (accuracy %, latency ms, false positive %)
- [ ] Discussion: limitations acknowledged
- [ ] Conclusion: summarises contribution + future work
- [ ] All claims supported by experimental results

### Figures and Data
- [ ] Figure 1: hardware photo + mounting (300 DPI)
- [ ] Figure 2: system architecture diagram
- [ ] Figure 3: detection pipeline flowchart
- [ ] Figure 4: bbox_w vs distance scatter plot (calibration)
- [ ] Figure 5: accuracy results chart
- [ ] Figure 6: latency histogram
- [ ] All figures referenced in text
- [ ] All figures original (not reproduced from other papers)
