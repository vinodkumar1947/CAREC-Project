# CAREC Autonomy Workspace

This is the home of the ROS 2 simulation-first stack. The initial package skeleton will be created only after the interface architecture decision is reviewed.

Planned packages are documented in [`docs/architecture/AUTONOMY_ARCHITECTURE.md`](../docs/architecture/AUTONOMY_ARCHITECTURE.md).

## Environment check

Open the repository in its development container, then run:

```bash
./scripts/bootstrap.sh --check
```

No physical wheelchair, embedded board, sensor, or GPU is required.
